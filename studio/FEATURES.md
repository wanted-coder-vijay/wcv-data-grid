# First-release scope

| Module       | Implemented                                                                                                                                                                                 | Remaining advanced capabilities                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Form builder | Visual field editing; seven types; drag and button reordering; required, number, email, date and option validation; visibility rules; steps; runtime preview; async submission; JSON export | Nested/repeating groups, localization and schema import/migrations                                                                      |
| Scheduler    | Week and agenda views; resource filtering; IANA timezone display; appointment editing; bounded weekly UTC recurrence; series editing/deletion; conflict checks across repeats; async saves  | Month/day time-grid views, monthly/daily RRULEs, local-wall-time DST recurrence, individual occurrence exceptions and drag rescheduling |
| Dashboard    | Metrics, charts and notes; editable widgets; drag and keyboard reordering; column-width resizing; search; preview; async save                                                               | Pixel resize handles, live data adapters, cross-widget date filters and collaborative layouts                                           |
| Workflow     | Five node types; pointer and keyboard movement; zoom and fit; connections; yes/no branches; graph validation; deterministic simulation; async save                                          | Durable execution, service integrations, pointer panning and versioned execution history                                              |
| Gantt        | Dates, owners, progress, milestones, finish-to-start links; cascade moves; drag/keyboard movement; day/week scale; baseline overlay; longest chain highlight; async save                    | Full critical-path/slack analysis, resource leveling, working calendars, other dependency types and large-plan virtualization           |
| Document     | Paragraph/heading/subheading/list/quote blocks; bold and italic; mentions; outline; templates; metadata attachments and upload callback; safe read view; Markdown/JSON exports; async save  | Collaborative editing, arbitrary inline marks/links, comments, history, tracked changes and PDF/DOCX export                             |
| Charts       | Smooth cubic, linear and step curves; hover tooltips; range brushing; motion and markers; MetricCard; SVG line/bar/area charts; negative/zero values; series toggles; period range sliders; pointer and keyboard inspection; drill-down callback; CSV/JSON exports                                | Streaming, server aggregation, annotations, irregular time scales, SVG/image export and downsampling                                    |

| Application architecture | Canvas/code/split modes; eight component kinds; five connector protocols; curve/elbow/straight edges; pan/zoom/fit; pointer and keyboard movement; erase; undo/redo; bounded validated JSON import; walkthrough; SVG/JSON/Markdown exports; async save | Live provider integrations, provisioning, collaborative editing, freehand drawing and a text DSL |

These are functional local modules with typed APIs, not substitutes yet for mature specialist libraries at their full feature depth. Publishing, deployment and production backend integration are separate steps.
